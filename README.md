# 久世管理器

新楓之谷的綜合補助小程序。

久世管理器是一個整合多種功能的應用程式，往後的更新也會新增更多功能，還請多加關注！

> 若有需要的功能更新請聯繫作者｜DC：xense999

![久世管理器](https://truth.bahamut.com.tw/s01/202609/forum/7650/02d70137be0c2490962caa85994402a0.PNG)

## 下載

前往 [Releases](https://github.com/xense999/kz-mana/releases/latest)，下載檔名結尾是 `_x64-setup.exe` 的安裝檔。

> Assets 裡另一個不帶 `setup` 的執行檔是給程式內「檢查更新」用的，不是給手動下載的。

## 特色功能

- 主頁面・團隊功能（跟隊友共用備忘錄與鬧鐘，隊長改一次全隊同步，時間到一起響）
- 角色經驗追蹤（浮動視窗）
- 角色資訊面板（角色資料、外型、近七日成長率…）
- 裝備屬性檢視（星火與卷軸加乘分開列、含平均每卷，可複製或下載）
- 計時器功能（出租、輪迴、燃燒、噴泉、各類型ＢＵＦＦ皆可支援並可支援組合鍵）
- 自訂計時器（可自行新增、改名、刪除，要開幾張開幾張）
- 出租計時（技能第一次觸發時跟著起算，中途再按不會洗掉客人的時間）
- 只限遊戲中觸發（預設開啟，在 Discord 打字按到同一顆鍵不會誤觸）
- 到期通報（響到你處理為止，卡片同時轉紅；音量可到 200%，可切音效、登機或人聲）
- 全部重置快捷鍵（設一顆全域鍵，按下把所有計時器一次歸零）
- 大卡／橫向列切換（一次要盯很多顆時切成一行一顆）
- 楓幣買賣換算（手續費扣完的實收與可獲得現金一併算出）
- 商城幣值換算（與當前幣值分開填，快速互換）
- 浮動視窗（三頁各一個，可拖移、透明度可調；開關、位置與大小下次開會還原，隨著遊戲隱藏）
- 序號管理器（付費功能：可快速整理序號、批量交貨、貼文招客，用完從庫存永久移除）
- 紙娃娃系統（免序號：試穿現金道具、稜鏡染色與混染、換動作與背景，存成 PNG／GIF）
- 關閉收進系統匣（按 X 只是收起來，計時與快捷鍵繼續跑；也可以設定成直接結束）
- 自動檢查本程式更新（可透過設定頁面右下角「關於」檢查更新狀況）
- 開啟時會自動置於畫面角落（預設右下角，可在設定選擇四個角落）
- 多色 / 暗色主題（亮色可自行調整色相與明暗）

## 使用方式

### 🔸 主頁面 － 團隊功能

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/8aac5afb6246fd5f0273a87662f211e2.PNG">
</p>

**🔹 畫面**

- 左邊是備忘錄：團隊寫的排版文字（集合時間、打法、注意事項、連結），一頁一個團隊，最後一頁是作者公告
- 右邊是鬧鐘：所有團隊的鬧鐘排在一起，最快要響的在最上面；今天不會響的是灰色
- 點一下鬧鐘卡片看重複時間，再點看是哪個團隊的，再點回到名稱

**🔹 加入團隊（隊員）**

- 右下角「團隊管理」→「加入團隊」，輸入隊長給的代碼（長得像 `KZ-XXXX-XX`），只看不需要密碼
- 最多加入 5 個團隊，左邊用下方的箭頭或圓點切換
- 退出：「團隊管理」→ 點進那個團隊 →「退出團隊」，退出後那個團隊的鬧鐘就不會再響

**🔹 建立與編輯（隊長）**

- 「團隊管理」→「建立團隊」，只要填團隊名稱；一台電腦最多 3 個
- 建好會給**團隊代碼**（貼給隊友加入）與**管理密碼**（要編輯才用得到）
- 管理密碼**只會顯示這一次**，請另外記下來（這台電腦會自動記住）
- 名牌卡上的「編輯」會開啟編輯視窗，上方切換「備忘錄」和「共用鬧鐘」，改完按「套用」確認後才會送出
- 送出後隊友最慢 5 分鐘內會更新；主頁面左下角「立即同步」可以馬上抓最新的
- 幫忙編輯別人的團隊：跟隊長要管理密碼 →「團隊管理」→ 點進那個團隊 → 輸入管理密碼按「記住」

**🔹 備忘錄**

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/992dfa799343f03cafa964be28429929.PNG">
</p>

- 一行一行設定：標題、副標題、內文、小字；六種常用色或自己調色；靠左、置中、靠右
- 項目清單、編號清單、引用、重點框；選起來的字可以設粗體、斜體、底線、刪除線
- Tab 往內縮一層、Shift+Tab 往外（最多四層）
- 行首打 `- ` 變項目清單、`1. ` 變編號、`> ` 變引用；Ctrl+B／I／U 粗體／斜體／底線
- 連結：選字後按工具列的連結鈕填網址；滑鼠移上去一定會顯示真正的網址
- 程式碼（跟 Discord 一樣）：`` ` `` 包起來是行內程式碼，行首打 ` ``` ` 是程式碼區塊，可選語言自動上色
- 編輯視窗右上角可以切到 Markdown 模式直接用純文字打，切回來不會掉格式

**🔹 鬧鐘**

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/d53f9bc8e2ac4a905d3f8953ce2c372c.PNG">
</p>

- 每個鬧鐘：標題、幾點幾分、重複方式（每週固定星期幾，或單次指定日期）、提前幾分鐘
- 提前 N 分鐘：提前那一刻先響一次，準點再響一次；時間一律是台灣時間
- 時間到會響兩輪「叮～咚～」並跳 Windows 通知，卡片變紅，點一下就關掉
- 通報方式選「人聲」的話，響完會再念一次鬧鐘標題；音量跟計時器的提醒音量一樣
- 管理器要開著才會響（收進系統匣也可以）
- 在提前的那段時間內才打開管理器，會馬上補響一次；已經過了準點的不會補

**🔹 管理密碼與團隊代碼**

- 拿到管理密碼的人都能改內容、改名稱、甚至刪除團隊，只給信得過的人
- 有人離隊就到團隊設定按「變更」換一組新密碼；密碼打錯一次要等 5 秒才能再試
- 伺服器上只存密碼加密後的結果，連作者也看不到；忘記的話只能找作者重設
- 代碼就是觀看的鑰匙，拿到代碼的人都看得到內容；代碼外流時，隊長可以刪掉團隊重建一個
- 自己建立的團隊不能退出，不要了請直接刪除；刪除團隊和更換密碼都會再跳一次確認
- 30 天沒有任何人打開的團隊會自動刪除
- 網路斷線時畫面照樣顯示上次的內容，鬧鐘照樣會響，只是暫時不能改
- 兩個人同時編輯時，後送出的人會被擋下來，請重新打開編輯視窗、在最新的內容上再改一次

### 🔸 紙娃娃系統 － 委託功能選單，免序號

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/ec70b4be39b4112d3dd6a383f19d5846.JPG">
</p>

**🔹 第一次打開**

- 會自動找遊戲的資料夾，找不到的話會請你選楓之谷的 `Data` 資料夾，選過一次就會記住
- 第一次讀遊戲檔需要等一下，畫面上會顯示讀取中
- 一開始的角色沒有頭髮和臉型，從左邊挑喜歡的穿上

**🔹 穿搭**

- 左邊點部位，按「更換」或在部位上點兩下，打開選道具視窗
- 可以搜尋名稱或編號，點一下就穿上；視窗不會關，可以一直換
- 只列出現金道具；髮型和臉型每一款只列一次，顏色到右邊染
- 對部位按右鍵（或滑鼠移上去按 ✕）就脫掉；膚色和耳朵不能脫，只能換
- 左下「模板」可以把整套搭配連同動作、武器拿法存起來，點名字就整套換回去；同名會蓋掉原本那套

**🔹 角色與背景**

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/fa196873380d64c54f08c7a66ed359e3.JPG">
</p>

- 上方可換武器拿法（單手、雙手、火槍模式）、動作、背景，粒子可以開關
- 動作有站立、走路、警戒、跳躍、趴下、坐下、飛行、爬梯子、爬繩子……穿上武器會多出那把武器的攻擊動作
- 背景有純色（含透明）、商城試穿背景（角色會站在地上），以及角色資訊視窗的大圖、小圖
- 左鍵拖曳移動、滾輪縮放（背景會照遊戲的比例一起縮放），點兩下回到正中間
- 有動態特效或粒子的裝備會照遊戲的節奏播放；第一次讀粒子要等一下

**🔹 染色**

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202609/forum/7650/2797da86f2d8289fbee7e8760dec043d.JPG">
</p>

- 裝備：稜鏡染色，選色系（全部或只染其中一種顏色）後調色相、彩度、明度
- 頭髮、眼睛：混染，主色、混色各選一個，再拉比例；只要單色的話，主色和混色選同一個

**🔹 存圖**

- PNG、複製：可選透明背景、目前背景（跟畫面上看到的一模一樣）；選了遊戲背景時還能存成背景圖的大小
- 複製完可以直接貼到 Discord
- GIF：存整段動作與粒子，可選放大倍率（1～4 倍），最短 3 秒；由於 GIF 檔案限制，顯示可能會有偏差
- GIF 存很久的話，可以選 1 倍或先把粒子關掉
- 視窗標題旁的「i」有完整的使用說明

### 🔸 角色資訊 － 隊友鞭策神器

**🔹 基本設定**

- 點選下方「新增角色」，填入角色名稱即可完成設定
- 每 15 分鐘會自動更新，同時也備有更新按鈕（設有一分鐘冷卻）
- 卡片可以拖曳排順序；附有浮動視窗

**🔹 詳細資訊（右側開啟）**

- 左邊是身分：頭像、職業、伺服器、公會、等級、近七日最高戰鬥力與創角時間
- 用左右鍵翻頁：一頁是成長（七日／三十日／九十日成長率＋每日經驗表，升級那天會標記），一頁是裝備
- 裝備頁點一件看它的主屬性、潛能、星火與卷軸加乘（含衝了幾卷、平均每卷）
- 右上角可把屬性複製或下載成圖片；對角色圖片按右鍵可以儲存角色圖片

### 🔸 計時器

**🔹 基本介紹**

- 本頁面可開啟浮動視窗自動計時所設定好的卡片，其中所有的邏輯已經寫好，只需要填寫設定使用即可
- 時間到會開啟通知功能，並會一直響到有人處理，按「停止提醒」可將到期的卡片歸零

**🔹 基本設定須知**

- 左下角新增計時器可以新建一張新的卡片，可透過雙擊名稱更改名稱
- 每張卡片都可以設定監聽按鍵（按右鍵清除，支援組合鍵）
- 設定好技能冷卻時間（避免觸發多次重置時間）
- 正常於遊戲中使用技能【程式只有監聽有沒有按（觸發按鍵）】
- 「重置」按鈕滑上去可設一顆全域快捷鍵，設好即生效，按下把所有計時器一次歸零

### 🔸 交易換算

**🔹 基本介紹**

- 「買幣」填需求楓幣或約當現金，另一邊自己算出來，手續費扣完的實收楓幣一併列出
- 「賣幣」填持有楓幣或約當現金，算出可販售楓幣與可獲得現金
- 打進去的數字旁邊會直接標出談價用的級距，不必自己數零
- 右下角設定可切換楓幣單位（元／億）；商城幣值與當前幣值分開填

### 🔸 浮動視窗相關

**🔹 基本介紹**

- 各頁面可能會具有「浮動視窗」按鈕
- 滑鼠停在按鈕上會浮出窗口，可透過拖移更改透明度與開關「文字陰影」
- 交易換算的面板可以直接在上面打字，改的是同一份資料，切回主視窗兩邊一致

### 🔸 序號管理器 － 此頁面為贊助頁面，需要開通序號

**🔹 基本介紹**

- 此頁面可用於快速管理序號，包含整理、發包、廣告（整理格式）、快速兌換及其他功能為一身
- 「新增庫存」可直接貼上一整串整行的序號：「時間、名稱、序號」，右邊會即時預覽切法，可進行調整
- 在庫存卡片上左右拖曳選這次要給幾組；右邊可以填單價，下方常駐顯示總計
- 按「鎖定」定案，接著「複製交貨」選 DC、LINE 或存成文字檔
  （交貨完按「已使用」，那批序號從庫存永久移除）
- 「貼文整理」把整份庫存排成表格，可直接貼去用於廣告

**🔹 快速兌換**

- 可一次貼一整串原始序號進去，右邊即時預覽實際會貼出去的內容
  （可自訂切點，並即時預覽實際內容）
- 按「開始」後第一筆先進剪貼簿，之後每次在遊戲裡貼上，就自動換下一筆、用掉的那行刪掉
  （只認遊戲在前景時的 Ctrl+V，在別的程式貼東西不會跳掉序號）

### 🔸 關閉與結束

**🔹 基本介紹**

- 按視窗右上角的 X 預設是收到右下角的系統匣，計時器與快捷鍵繼續運作（也可以在設定改成直接結束）
- 點系統匣的圖示把視窗叫回來
- 要真的結束，對系統匣圖示按右鍵選「結束」

## 安全性說明

- 按鍵綁定用的是只監聽、不攔截的方式，不會送出任何按鍵到遊戲，也不會替你操作角色
- 角色資料來自官方公開 API，查詢只帶角色名稱；程式不儲存也不上傳任何帳號密碼
- 紙娃娃系統只讀取電腦裡的遊戲檔，不會修改遊戲檔
- 本程式不是遊戲橘子所開發的官方程式，使用上請自行斟酌

## 系統需求

Windows 10 以上。首次執行如果出現 SmartScreen 提示，選「其他資訊 → 仍要執行」。
紙娃娃系統需要電腦裡有安裝楓之谷。
