# 久世管理器

新楓之谷的角色與交易輔助工具（Windows）。

## 下載

前往 [Releases](https://github.com/xense999/kz-mana/releases/latest)，下載檔名結尾是 `_x64-setup.exe` 的安裝檔。

> Assets 裡另一個不帶 `setup` 的執行檔是給程式內「檢查更新」用的，不是給手動下載的。

## 功能

- **角色資訊** — 等級與經驗進度、每日成長、近七日最高戰鬥力、裝備與外觀
- **計時器** — 出租、加持、輪迴、燃燒、靈魂亞努斯的倒數，可綁全域快捷鍵；靈魂亞努斯可設冷卻，冷卻內再按不重算
- **交易換算** — 楓幣現金交易的手續費換算，楓幣單位可切元／億
- **序號管理器**（付費）— 自動分割整理序號、自動排列DC格式廣告、快速發序號
- **序號管理器「快速兌換」**：貼一整串序號進去，一次發一筆到剪貼簿，在遊戲裡貼上就自動換下一筆。貼上時右邊即時預覽，每行前面有名稱的話可用空格切點只取序號。


導覽列最右邊的「付費功能」，第一次進去要輸入開通序號，開過一次就永久記住。

## 系統需求

Windows 10 以上。首次執行如果出現 SmartScreen 提示，選「其他資訊 → 仍要執行」。

## 更新

程式內：設定 → 右下角 `i` → 檢查更新。
