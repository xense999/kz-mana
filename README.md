# 久世管理器

新楓之谷的綜合補助小程序：計時、提醒、團隊行程、角色追蹤、試穿、錄影截圖，整合在一個程式裡。

> 若有需要的功能更新請聯繫作者｜DC：xense999

![久世管理器](https://truth.bahamut.com.tw/s01/202609/forum/7650/02d70137be0c2490962caa85994402a0.PNG)

## 介紹

相信很多人在遊戲中常常會遇到：

- 放置技能忘記按、經驗ＢＵＦＦ忘記開、燃燒時間到了還要去計時什麼時候釋放下一個
- 隨時要提醒自己今天要簽到、打怪物公園、打水道，或是跟好友之間的團打時間常常忘記

過往我們常常需要花費很多時間提醒自己，卻沒有一個好的程式同時整合這些功能。
於是有了久世管理器：跟好友之間可以共用提醒事項、行程表與公告欄，同時也能互相「稽查」彼此的成長（？

希望每個人都可以順利、便利地遊玩這個遊戲！

## 特色功能

- 主頁面・團隊功能（跟隊友共用備忘錄、提醒事項與行程表，團隊管理員改一次全隊同步，時間到一起響）
- 團隊成員與代表角色（行程可以分派給特定成員，沒分派給你的不會響）
- 個人待辦（自己的行程、每日待辦、本週待辦，只存在這台電腦；支援多角色與帳號分組）
- 角色牆（最多 20 隻角色，可分成好幾個帳號）
- 角色經驗追蹤（浮動視窗）
- 角色資訊面板（角色資料、外型、近七日成長率…）
- 裝備屬性檢視（星火與卷軸加乘分開列、含平均每卷，可複製或下載）
- 計時器功能（出租、輪迴、燃燒、噴泉、各類型ＢＵＦＦ皆可支援並可支援組合鍵）
- 自訂計時器（可自行新增、改名、刪除，要開幾張開幾張；每張卡可設專用音效）
- 出租計時（技能第一次觸發時跟著起算，中途再按不會洗掉客人的時間）
- 只限遊戲中觸發（預設開啟，在 Discord 打字按到同一顆鍵不會誤觸）
- 到期通報（響到你處理為止，卡片同時轉紅；音量可到 200%，可切音效、登機、人聲或自訂音效）
- 全部重置／全部開關快捷鍵（全部開關會連同浮動視窗一起開關）
- 大卡／橫向列切換（一次要盯很多顆時切成一行一顆）
- 楓幣買賣換算（手續費扣完的實收與可獲得現金一併算出）
- 商城幣值換算（與當前幣值分開填，快速互換）
- ＶＩＰ換算（免費：算出升級或維持 VIP 最少要花多少錢）
- 浮動視窗（三頁各一個，可拖移、透明度可調；開關、位置與大小下次開會還原，隨著遊戲隱藏）
- 實用工具：影像錄製（GIF／MP4，可錄電腦聲音與麥克風、預覽剪輯與裁切）
- 實用工具：快速截圖（自由矩形、當前視窗，截完直接複製）
- 實用工具：Discord 通報（閃退、行程、每週待辦提醒）
- 序號管理器（訂閱功能：整理序號、組合包、批量交貨、販售文與販售圖片，用完從庫存永久移除）
- 時裝管理器（訂閱功能：整理要賣的時裝與套組，產生販售文與販售圖片）
- 紙娃娃系統（免序號：試穿現金道具、稜鏡染色與混染、混色預覽、換動作與背景，存成 PNG／GIF）
- 關閉收進系統匣（按 X 只是收起來，計時與快捷鍵繼續跑；也可以設定成直接結束）
- 自動檢查本程式更新（可透過設定頁面右下角「關於」檢查更新狀況）
- 開啟時會自動置於畫面角落（預設右下角，可在設定選擇四個角落）
- 多色 / 暗色主題（亮色可自行調整色相與明暗）

## 功能介紹

### 🔸 主頁面 － 團隊功能

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202610/forum/7650/eea95e01f6dd9302ce13010c7278047f.PNG">
  <img src="https://truth.bahamut.com.tw/s01/202610/forum/7650/fb7de3cf6ea1f438dee17d70d08b9d7e.PNG">
</p>

**🔹 畫面**

- 左邊是備忘錄：團隊寫的排版文字（集合時間、打法、注意事項、連結），一頁一個團隊，最後一頁是作者公告
- 右邊是今日待辦：所有團隊的提醒與行程排在一起，最快要響的在最上面；可以在個人待辦的「設定」選列今天、三天或七天內的
- 右邊那張卡可以切到「每日待辦」，點一下打勾，每天 0:00 自動清掉
- 左下角「本週待辦」列出所有團隊與個人的本週待辦；左鍵打勾（每週四 0:00 清掉），右鍵只在自己的電腦關掉
- 「本週待辦」名牌上的「行程表」可以打開本週行程表（所有團隊的行程合成一週七天），角色鈕打開角色牆

**🔹 加入團隊（隊員）**

- 右下角「團隊管理」→「加入團隊」，輸入團隊管理員給的代碼（長得像 `KZ-XXXX-XX`）按「下一步」，再到角色牆點一隻角色當代表
- 選代表時會先向官方查這隻角色，查不到不能加入
- 最多加入 5 個團隊，左邊用下方的箭頭或圓點切換
- 換代表或退出：在角色牆對角色按右鍵，勾選它代表哪些團隊；退出後那個團隊的提醒就不會再響

**🔹 建立與編輯（團隊管理員）**

- 「團隊管理」→「建立團隊」，填團隊名稱並選一隻代表角色；一台電腦最多 3 個
- 建好會給**團隊代碼**（貼給隊友加入）與**管理密碼**（要編輯才用得到）
- 管理密碼**只會顯示這一次**，請另外記下來（這台電腦會自動記住）
- 名牌卡上的「編輯頁」會開啟編輯視窗，可以切換「備忘錄」「提醒事項」「行程表」「團隊成員」，改完按「套用」確認後才會送出
- 送出後隊友最慢 5 分鐘內會更新
- 「團隊成員」分頁用角色牆的樣子列出全隊，團隊管理員可以把人移出團隊；左下角可以直接切換到其他團隊
- 幫忙編輯別人的團隊：跟團隊管理員要管理密碼 →「團隊管理」→ 點進那個團隊 → 輸入管理密碼按「記住」

**🔹 備忘錄**

- 一行一行設定：標題、副標題、內文、小字；六種常用色或自己調色；靠左、置中、靠右
- 項目清單、編號清單、引用、重點框；選起來的字可以設粗體、斜體、底線、刪除線
- Tab 往內縮一層、Shift+Tab 往外（最多四層）
- 行首打 `- ` 變項目清單、`1. ` 變編號、`> ` 變引用；Ctrl+B／I／U 粗體／斜體／底線
- 連結：選字後按工具列的連結鈕填網址；滑鼠移上去一定會顯示真正的網址
- 程式碼（跟 Discord 一樣）：`` ` `` 包起來是行內程式碼，行首打 ` ``` ` 是程式碼區塊，可選語言自動上色
- 編輯視窗右上角可以切到 Markdown 模式直接用純文字打，切回來不會掉格式

**🔹 行程表與本週待辦**

- 備忘錄工具列的「行程表」會插入一個週一～週日加「單次」的區塊
- 在某一天底下寫「20:30 團隊一 困人馬」就是每週那天的行程；「單次」寫「10/3 22:00 臨時加場」只排那一次
- 每一筆行程可以設定提前幾分響（預設 5 分），也可以分派給特定成員；沒分派給你的不會響
- 一次勾好幾天新增的行程是一組，改時間、標題、分派整組一起改
- 「本週待辦」是這週要做完、不用寫時間的事；內建「派對樂園」（每兩週一次）

**🔹 提醒事項**

- 每個提醒：標題、幾點幾分、重複方式（每週固定星期幾，或單次指定日期）、提前幾分鐘
- 提前 N 分鐘：提前那一刻先響一次，準點再響一次；時間一律是台灣時間
- 時間到會響兩輪「叮～咚～」並跳 Windows 通知，卡片變紅，點一下就關掉
- 通報方式選「人聲」的話，響完會再念一次標題；音量跟計時器的提醒音量一樣
- 管理器要開著才會響（收進系統匣也可以）
- 在提前的那段時間內才打開管理器，會馬上補響一次；已經過了準點的不會補

**🔹 管理密碼與團隊代碼**

- 拿到管理密碼的人都能改內容、改名稱、甚至刪除團隊，只給信得過的人
- 有人離隊就到團隊設定按「變更」換一組新密碼；密碼打錯一次要等 5 秒才能再試
- 伺服器上只存密碼加密後的結果，連作者也看不到；忘記的話只能找作者重設
- 代碼就是觀看的鑰匙，拿到代碼的人都看得到內容；代碼外流時，團隊管理員可以刪掉團隊重建一個
- 自己建立的團隊不能退出，不要了請直接刪除；刪除團隊和更換密碼都會再跳一次確認
- 30 天沒有任何人打開的團隊會自動刪除
- 網路斷線時畫面照樣顯示上次的內容，提醒照樣會響，只是暫時不能改
- 兩個人同時編輯時，後送出的人會被擋下來，請重新打開編輯視窗、在最新的內容上再改一次

### 🔸 個人待辦與角色牆

<p align="center">
  <img src="https://truth.bahamut.com.tw/s01/202610/forum/7650/f11d2b87cc5b5d950d9e659c3221bcee.PNG">

**🔹 個人待辦**

- 主頁面右下角「團隊管理」左邊的「個人待辦」：替自己的角色排行程與待辦，只存在這台電腦
- 「行程表」分頁：有時間的行程，時間到會響，列在今日待辦
- 「每日待辦」分頁：內建「簽到」（每日任務、活動每日 A／B／C）與「狩獵」（狩獵型簽到、怪物公園），也可以自訂
- 「本週待辦」分頁：內建「每週任務」（艾爾達斯的請求、史詩副本、終極怪物公園、紅月之森、公會城狩獵）與「固定活動」（派對樂園），也可以自訂
- 每一項可以選「每隻角色」（切到哪隻就列哪隻的，勾勾各記各的）或「帳號共用」（同一個帳號的角色共用一個勾）
- 按住自訂卡片上下拖可以換順序，主頁面的順序跟著變

**🔹 角色牆**

- 主頁面的角色鈕打開角色牆，最多 20 隻角色，會自動抓角色外型；點一下角色就切過去
- 左下角「管理帳號」：左右兩區各選一個帳號，把角色拖到另一邊就換到那個帳號；還沒分組的角色都算「預設帳號」
- 對角色按右鍵，勾選它代表哪些團隊

**🔹 基本設定**

- 點選下方「新增角色」，填入角色名稱即可完成設定
- 每 15 分鐘會自動更新，同時也備有更新按鈕（設有一分鐘冷卻）
- 卡片可以直接拖曳排順序；附有浮動視窗

**🔹 詳細資訊（右側開啟）**

- 左邊是身分：頭像、職業、伺服器、公會、等級、近七日最高戰鬥力與創角時間
- 用左右鍵翻頁：一頁是成長（七日／三十日／九十日成長率＋每日經驗表，升級那天會標記），一頁是裝備
- 裝備頁點一件看它的主屬性、潛能、星火與卷軸加乘（含衝了幾卷、平均每卷）
- 右上角可把屬性複製或下載成圖片；對角色圖片按右鍵可以儲存角色圖片

**🔹 基本介紹**

- 本頁面可開啟浮動視窗自動計時所設定好的卡片，其中所有的邏輯已經寫好，只需要填寫設定使用即可
- 時間到會開啟通知功能，並會一直響到有人處理，按「停止提醒」可將到期的卡片歸零

**🔹 基本設定須知**

- 左下角新增計時器可以新建一張新的卡片，可透過雙擊名稱更改名稱
- 每張卡片都可以設定監聽按鍵（按右鍵清除，支援組合鍵）
- 設定好技能冷卻時間（避免觸發多次重置時間）；計時器停著時雙擊時間數字可以只設定那一張
- 每張卡可以設定自己的專用音效（左鍵選音效檔，右鍵取消）
- 正常於遊戲中使用技能【程式只有監聽有沒有按（觸發按鍵）】
- 「重置」按鈕滑上去可設一顆全域快捷鍵，設好即生效，按下把所有計時器一次歸零
- 「全部關閉／全部開啟」把每張卡的開關連同浮動視窗一起開關，也可以設快捷鍵

**🔹 第一次打開**

- 會自動找遊戲的資料夾，找不到的話會請你選楓之谷的 `Data` 資料夾，選過一次就會記住
- 第一次讀遊戲檔需要等一下，畫面上會顯示讀取中
- 一開始的角色沒有頭髮和臉型，從左邊挑喜歡的穿上

**🔹 穿搭**

- 左邊點部位，按「更換」或在部位上點兩下，打開選道具視窗
- 可以搜尋名稱或編號，點一下就穿上；視窗不會關，可以一直換
- 只列出現金道具；髮型和臉型每一款只列一次，顏色到右邊染
- 對部位按右鍵（或滑鼠移上去按 ✕）就脫掉；膚色和耳朵不能脫，只能換
- 可以試穿表情臉飾，看得到戴上後的表情
- 左下「模板」可以把整套搭配連同動作、武器拿法存起來，每一格畫出那一套穿起來的樣子；刪除前會先確認

**🔹 角色與背景**

- 上方可換武器拿法（單手、雙手、火槍模式）、動作、背景，粒子可以開關
- 動作有站立、走路、警戒、跳躍、趴下、坐下、飛行、爬梯子、爬繩子……穿上武器會多出那把武器的攻擊動作
- 背景有純色（含透明）、商城試穿背景（角色會站在地上），以及角色資訊視窗的背景
- 左鍵拖曳移動、滾輪縮放（背景會照遊戲的比例一起縮放），點兩下回到正中間
- 有動態特效或粒子的裝備會照遊戲的節奏播放；第一次讀粒子要等一下

**🔹 染色**

- 裝備：稜鏡染色，選色系（全部或只染其中一種顏色）後調色相、彩度、明度
- 頭髮、眼睛：混染，主色、混色各選一個，再拉比例；只要單色的話，主色和混色選同一個
- 「混色預覽」：所有顏色配所有顏色各混 50% 一次看完，點一格就把頭髮換成那個顏色

**🔹 存圖**

- PNG、複製：可選透明背景、目前背景（跟畫面上看到的一模一樣）；選了遊戲背景時還能存成背景圖的大小
- 複製完可以直接貼到 Discord
- GIF：存整段動作與粒子，可選放大倍率（1～4 倍），最短 3 秒；由於 GIF 檔案限制，顯示可能會有偏差
- GIF 存很久的話，可以選 1 倍或先把粒子關掉
- 視窗標題旁的「i」有完整的使用說明

### 🔸 實用工具

**🔹 影像錄製**

- 「框選範圍」拖一個框，或「選擇視窗」點一個視窗（視窗被擋住也錄得到），按熱鍵開始／停止
- 錄影範圍會顯示四個角的框線，左上角標籤寫著熱鍵；錄影中顯示計時
- 錄完按「預覽」：可以剪頭尾、裁切比例（16:9、9:16、1:1、4:3 或自訂），存成 GIF（一般／低畫質）或 MP4
- 設定左下角「聲音設定」：電腦聲音（預設開）、麥克風（預設關，可選要用哪一個）；聲音只錄進 MP4
- 錄影時直接寫進硬碟的暫存檔，長時間錄也不會吃記憶體

**🔹 快速截圖**

- 「自由矩形」：畫面先定格，右下角有放大鏡看像素，按 C 複製色碼；拉完就複製
- 「當前視窗」：直接截現在正在用的視窗
- 可以設定每次截圖後也存一張圖檔

**🔹 Discord 通報**

- 填一個 Webhook，可以分開開關「閃退通報」「行程通報」「每週待辦提醒」，都會 @here
- 每週待辦提醒每天在指定時間發一次，每隻角色分開列出還沒辦的事；發之前會先抓團隊最新的待辦

### 🔸 浮動視窗相關

## 安全性說明

- 按鍵綁定用的是只監聽、不攔截的方式，不會送出任何按鍵到遊戲，也不會替你操作角色
- 角色資料來自官方公開 API，查詢只帶角色名稱；程式不儲存也不上傳任何帳號密碼
- 紙娃娃系統、時裝管理器只讀取電腦裡的遊戲檔，不會修改遊戲檔
- 錄影與截圖只存在你自己的電腦，不會上傳
- 本程式不是遊戲橘子所開發的官方程式，使用上請自行斟酌
