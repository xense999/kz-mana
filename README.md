# 久世管理器

新楓之谷的角色與交易輔助工具（Windows）。

久世管理器是一個整合多種功能的應用程式，之後也會新增更多功能，還請耐心等候！
未來，希望每個人都可以順利、便利地遊玩這個遊戲！

## 特色功能

- 角色經驗追蹤（浮動視窗）
- 角色資訊面板（角色資料、外型、近七日成長率…）
- 裝備屬性檢視（星火與卷軸加乘分開列、含平均每卷，可複製或下載）
- 計時器功能（出租、輪迴、燃燒、噴泉、各類型ＢＵＦＦ皆可支援並可支援組合鍵）
- 自訂計時器（可自行新增、改名、刪除，要開幾張開幾張）
- 出租計時（技能第一次觸發時跟著起算，中途再按不會洗掉客人的時間）
- 只限遊戲中觸發（預設開啟，在 Discord 打字按到同一顆鍵不會誤觸）
- 到期通報（響到你處理為止，卡片同時轉紅；音量可到 200%，可切音效或人聲）
- 全部重置快捷鍵（設一顆全域鍵，按下把所有計時器一次歸零）
- 大卡／橫向列切換（一次要盯很多顆時切成一行一顆）
- 楓幣買賣換算（手續費扣完的實收與可獲得現金一併算出）
- 商城幣值換算（與當前幣值分開填，快速互換）
- 浮動視窗（三頁各一個，永遠置頂、可拖、透明度可調；開關、位置與大小下次開會還原）
- 序號管理器（付費功能：可快速整理序號、批量交貨、貼文招客，用完從庫存永久移除）
- 關閉收進系統匣（按 X 只是收起來，計時與快捷鍵繼續跑）
- 開機時啟動（登入 Windows 後自動開啟）
- 自動檢查本程式更新（可透過設定頁面右下角「關於」檢查更新狀況）
- 開啟時會自動置於畫面右下角
- 多色 / 暗色主題（亮色可自行調整色相與明暗）

## 使用方式

### 🔸 角色資訊 － 隊友鞭策神器

**🔹 基本設定**

- 點選下方「新增角色」，填入角色名稱即可完成設定
- 每 15 分鐘會自動更新，同時也備有更新按鈕（設有一分鐘冷卻）
- 卡片可以拖曳排順序；附有浮動視窗

**🔹 詳細資訊（右側開啟）**

- 左邊是身分：頭像、職業、伺服器、公會、等級、近七日最高戰鬥力與創角時間
- 用左右鍵翻頁：一頁是成長（七日／三十日／九十日成長率＋每日經驗表，升級那天會標記），一頁是裝備
- 裝備頁點一件看它的主屬性、潛能、星火與卷軸加乘（含衝了幾卷、平均每卷）
- 右上角可把屬性複製或下載成圖片；對角色圖片按右鍵可以儲存角色圖片

### 🔸 計時器

**🔹 基本介紹**

- 本頁面可開啟浮動視窗自動計時所設定好的卡片，其中所有的邏輯已經寫好，只需要填寫設定使用即可
- 時間到會開啟通知功能，並會一直響到有人處理，按「停止提醒」可將到期的卡片歸零

**🔹 基本設定須知**

- 左下角新增計時器可以新建一張新的卡片，可透過雙擊名稱更改名稱
- 每張卡片都可以設定監聽按鍵（按右鍵清除，支援組合鍵）
- 設定好技能冷卻時間（避免觸發多次重置時間）
- 正常於遊戲中使用技能【程式只有監聽有沒有按（觸發按鍵）】
- 「重置」按鈕滑上去可設一顆全域快捷鍵，設好即生效，按下把所有計時器一次歸零

### 🔸 交易換算

**🔹 基本介紹**

- 「買幣」填需求楓幣或約當現金，另一邊自己算出來，手續費扣完的實收楓幣一併列出
- 「賣幣」填持有楓幣或約當現金，算出可販售楓幣與可獲得現金
- 打進去的數字旁邊會直接標出談價用的級距，不必自己數零
- 右下角設定可切換楓幣單位（元／億）；商城幣值與當前幣值分開填

### 🔸 浮動視窗相關

**🔹 基本介紹**

- 各頁面可能會具有「浮動視窗」按鈕
- 滑鼠停在按鈕上會浮出窗口，可透過拖移更改透明度與開關「文字陰影」
- 交易換算的面板可以直接在上面打字，改的是同一份資料，切回主視窗兩邊一致

### 🔸 序號管理器 － 此頁面為贊助頁面，需要開通序號

**🔹 基本介紹**

- 此頁面可用於快速管理序號，包含整理、發包、廣告（整理格式）、快速兌換及其他功能為一身
- 「新增庫存」可直接貼上一整串整行的序號：「時間、名稱、序號」，右邊會即時預覽切法，可進行調整
- 在庫存卡片上左右拖曳選這次要給幾組；右邊可以填單價，下方常駐顯示總計
- 按「鎖定」定案，接著「複製交貨」選 DC、LINE 或存成文字檔
  （交貨完按「已使用」，那批序號從庫存永久移除）
- 「貼文整理」把整份庫存排成表格，可直接貼去用於廣告

**🔹 快速兌換**

- 可一次貼一整串序號進去，右邊即時預覽實際會貼出去的內容
  （可自訂切點，並即時預覽實際內容）
- 按「開始」後第一筆先進剪貼簿，之後每次在遊戲裡貼上，就自動換下一筆、用掉的那行刪掉
  （只認遊戲在前景時的 Ctrl+V，在別的程式貼東西不會跳掉序號）

### 🔸 關閉與結束

**🔹 基本介紹**

- 按視窗右上角的 X 只是收到右下角的系統匣，計時器與快捷鍵繼續運作
- 點系統匣的圖示把視窗叫回來
- 要真的結束，對系統匣圖示按右鍵選「結束」

## 安全性說明

- 按鍵綁定用的是只監聽、不攔截的方式，不會送出任何按鍵到遊戲，也不會替你操作角色
- 角色資料來自官方公開 API，查詢只帶角色名稱；程式不儲存也不上傳任何帳號密碼
- 本程式不是遊戲橘子所開發的官方程式，使用上請自行斟酌
